# Videos Directory

Place your video ad files here.

## Recommended Format
- MP4 format
- H.264 encoding
- 16:9 aspect ratio
- File size under 50MB for fast loading

## Current Ads
- `your-ad-video.mp4` - Replace with your actual video ad

## Usage
The video ad system will look for videos in this directory. Update the video path in the chapter page component to match your filename.
